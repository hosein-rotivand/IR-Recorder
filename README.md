# IR Recorder

ضبط‌کننده‌ی شخصی و حرفه‌ای صفحه برای ویندوز. **کسب و مال**

## حالت‌های ضبط

| حالت | خروجی | توضیح |
|---|---|---|
| ریلز / شورتس | 1080×1920 · 9:16 | کادر عمودی قفل‌شده، قابل جابه‌جایی و تغییر اندازه |
| یوتیوب | 1920×1080 · 16:9 | کادر افقی قفل‌شده |
| تب مرورگر | اندازه‌ی کادر | کادر آزاد؛ روی محتوای تب بکش تا نوار آدرس ضبط نشود |
| تمام صفحه | رزولوشن مانیتور (حداکثر 2560) | کل مانیتور انتخاب‌شده |

موقعیت کادر هر حالت ذخیره می‌شود و دفعه‌ی بعد همان‌جا باز می‌شود.

## قابلیت‌ها

- **کادر دنبال ماوس (Follow Cam):** وقتی ماوس به لبه‌ی کادر برسد، کادر با حرکت فنری (critically damped spring) نرم و بی‌پرش دنبالش می‌رود. سه سرعت دارد: خیلی نرم، متعادل و سریع. مخصوص ریلز ساخته شده و در یوتیوب و تب مرورگر هم کار می‌کند.
- **ذخیره‌ی فوری:** ویدیو با انکودر سخت‌افزاری H.264 ضبط می‌شود و بدون تبدیل دوباره ذخیره می‌شود. برای ادیت حرفه‌ای می‌توانی 60fps ثابت را انتخاب کنی.
- **زوم خودکار:** با هر کلیک چپ نرم زوم می‌کند، تصویر دنبال ماوس می‌رود و بعد از حدود ۲.۵ ثانیه بی‌کاری زوم برمی‌گردد.
- **وبکم دایره‌ای:** چهار گوشه و سه اندازه. در ریلز از ناحیه‌ی کپشن اینستاگرام دور می‌ماند.
- **هایلایت کلیک:** موج بنفش برای کلیک چپ و زرد برای کلیک راست.
- **نمایش کلیدها:** حالت «فقط میانبرها» (پیش‌فرض و امن برای رمزها) یا «همه‌ی کلیدها».
- **طراحی روی صفحه:** قلم، فلش و کادر، با ۵ رنگ، ۳ ضخامت و Undo.
- **صدا:** صدای سیستم (loopback ویندوز) و میکروفون با حذف نویز، که با هم میکس می‌شوند.
- **نوار کنترل شناور:** تایمر، توقف موقت، قطع میکروفون، زوم، طراحی و پایان ضبط.
- **خروجی:** MP4 با H.264 و 60fps ثابت و صدای AAC، با faststart برای آپلود سریع.

تمام جلوه‌ها مستقیم داخل ویدیو رندر می‌شوند و پنجره‌های خود برنامه (کادر، نوار کنترل، ابزار طراحی) در ویدیو دیده نمی‌شوند.

## میانبرها

| کار | کلید |
|---|---|
| شروع / پایان ضبط | `Alt+Shift+R` |
| توقف موقت | `Alt+Shift+P` |
| طراحی روی صفحه | `Alt+Shift+D` |
| پاک کردن طراحی | `Alt+Shift+X` |
| روشن/خاموش زوم | `Alt+Shift+Z` |
| دنبال کردن ماوس | `Alt+Shift+F` |
| جابه‌جایی وبکم | `Alt+Shift+C` |
| قطع میکروفون | `Alt+Shift+M` |

در حالت طراحی: `1` قلم، `2` فلش، `3` کادر، `Ctrl+Z` برگشت، `Esc` خروج.
در انتخاب کادر: `Enter` یا دابل‌کلیک برای شروع، `Esc` برای لغو.

## اجرا و ساخت

پیش‌نیاز: Node.js 22 و ویندوز ۱۰ نسخه‌ی 2004 به بالا، یا ویندوز ۱۱.

```bash
npm install
npm start
```

ساخت فایل نصبی و نسخه‌ی Portable در پوشه‌ی `dist`:

```bash
npm run dist
```

بررسی سینتکس همه‌ی فایل‌ها:

```bash
npm run check
```

اگر پروژه را روی GitHub بگذاری، workflow موجود در `.github/workflows/build.yml` روی ویندوز build می‌گیرد و فایل `.exe` را به‌صورت Artifact تحویل می‌دهد.

## ساختار

```
src/
├─ main/                 Main process
│  ├─ main.js            Bootstrap، IPC، میانبرها، مجوزها
│  ├─ kasbo-session.js   چرخه‌ی ضبط: انتخاب ← آماده‌سازی ← شمارش ← ضبط ← انکود
│  ├─ kasbo-settings.js  تنظیمات با اعتبارسنجی Schema
│  ├─ kasbo-input-hook.js ماوس و کیبورد سراسری
│  ├─ kasbo-encoder.js   ذخیره‌ی فوری یا 60fps ثابت با FFmpeg
│  └─ kasbo-windows.js   ساخت پنجره‌ها
├─ preload/preload.js    پل امن با Whitelist کانال‌ها
└─ renderer/
   ├─ panel/             پنل اصلی
   ├─ overlay/           انتخاب کادر، شمارش معکوس، طراحی
   ├─ recorder/          موتور ضبط (Compositor، دوربین زوم، Follow Cam فنری)
   ├─ controlbar/        نوار کنترل شناور
   └─ shared/            استایل پایه و رسم مشترک
```

## Dependencyها

- `ffmpeg-static`: باینری FFmpeg برای ساخت MP4
- `uiohook-napi`: گرفتن کلیک و کلید در سطح سیستم، برای هایلایت، زوم و نمایش کلیدها

اگر `uiohook-napi` بارگذاری نشود، برنامه همچنان ضبط می‌کند و فقط همین سه جلوه غیرفعال می‌شوند.

## امنیت

- `contextIsolation`، `sandbox` و غیرفعال بودن `nodeIntegration` در همه‌ی پنجره‌ها
- CSP سخت‌گیرانه در همه‌ی صفحه‌ها
- Whitelist کانال‌های IPC و بررسی فرستنده‌ی هر پیام در Main
- اعتبارسنجی همه‌ی ورودی‌ها: تنظیمات، کادر و خطوط طراحی
- باز کردن فایل فقط برای فایل‌هایی که خود برنامه ساخته
- جلوگیری از Navigation و باز شدن پنجره‌ی جدید
- اجرای FFmpeg بدون shell و با آرگومان آرایه‌ای
